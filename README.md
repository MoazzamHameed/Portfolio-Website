# Moazzam Hameed Portfolio Website

Modern and responsive personal portfolio built with React, Tailwind CSS, and Framer Motion.

## Tech Stack

- React.js + Vite
- Tailwind CSS v4
- Framer Motion (section reveal + animated interactions)
- Lucide React + React Icons

## Features

- Premium glassmorphism-inspired design with gradient accents
- Dark and light mode toggle with local storage persistence
- Sticky responsive navbar and smooth scrolling
- Hero typing-style rotating title animation
- Animated skill progress bars
- Project filtering by category
- Scroll-to-top button
- SEO-friendly metadata
- Reusable component architecture

## Run Locally

1. Install dependencies:
	npm install

2. Start development server:
	npm run dev

3. Build for production:
	npm run build

4. Preview production build:
	npm run preview
